# ManageX 🌱

**ManageX** is a modular, self-hostable business management platform currently under development.

Instead of being built for a single industry, ManageX is designed around reusable modules that organizations can enable multiple times and configure to match their workflow. The goal is to provide a flexible foundation for managing businesses of all kinds—from restaurants and retail stores to warehouses and offices.

### Current Focus 🪼

- Multi-tenant organizations
- Modular architecture
- Role-based access control (RBAC)
- Instance-based permissions
- FastAPI + PostgreSQL backend
- Next.js frontend

> **Status:** 🚧 Work in Progress — the architecture is actively evolving and breaking changes are expected.
